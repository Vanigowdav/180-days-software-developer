# Day 38 — User Interface Design Fundamentals

## 1. Common Design Terms

Learning the shared vocabulary designers use helps in communicating clearly with them (contrast, hierarchy, scale, alignment, whitespace, etc. — all covered below).

---

## 2. Background and Foreground Contrast

- **Contrast** = the difference in color/brightness between background and foreground (text, icons, elements).
- Good contrast makes content easy to read and elements easy to distinguish.
- Poor contrast (e.g. light gray text on white) hurts readability and accessibility.
- Rule of thumb: dark text on light background, or light text on dark background, generally works best.

---

## 3. Visual Hierarchy

- **Visual hierarchy** = arranging elements so the eye naturally notices the most important things first.
- Achieved through size, color, spacing, and position — bigger/bolder/brighter elements draw attention first.
- Helps guide the user's eye through content in the intended order (e.g. headline → subheading → body text).

---

## 4. Scale

- **Scale** = the relative size of elements compared to each other.
- Larger elements appear more important; smaller elements recede.
- Used to create emphasis and hierarchy (e.g. a big heading vs small caption text).

---

## 5. Alignment

- **Alignment** = how elements line up with each other (left, right, center, or along invisible grid lines).
- Consistent alignment makes a design look organized and professional.
- Misaligned elements feel messy/unintentional, even if the difference is small.

---

## 6. Whitespace

- **Whitespace** (a.k.a. negative space) = empty space around/between elements.
- Not "wasted" space — it improves readability, reduces clutter, and helps group related content.
- More whitespace = cleaner, more breathable design; too little = cramped, overwhelming design.

---

## 7. Best Practices for Working with Images

- Use images that are relevant and support the content, not just decorative filler.
- Optimize image size/file size for faster page loads.
- Maintain consistent aspect ratios and quality across a design.
- Ensure images have appropriate alt text for accessibility.
- Avoid stretching/distorting images — keep proportions intact.

---

## 8. Progressive Enhancement

- **Progressive enhancement** = building a basic, functional version of a webpage first (works everywhere, even on older browsers/limited connections), then layering on advanced features/styling for browsers that support them.
- Ensures the core experience is accessible to everyone, while enhancing it for capable environments.
- Opposite approach: "graceful degradation" (start advanced, fall back when unsupported).

---

## Quick Recap

- **Contrast** → readability
- **Hierarchy** → guides attention
- **Scale** → shows importance
- **Alignment** → organized look
- **Whitespace** → breathing room, clarity
- **Images** → relevant, optimized, accessible
- **Progressive enhancement** → core experience works for everyone, enhanced for more capable browsers
