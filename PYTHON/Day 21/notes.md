# Day 21: Inheritance and Polymorphism

## Inheritance
Inheritance helps to reuse the code. With inheritance a subclass 
(or child class) can use the attributes and methods of a base 
class (or parent class).

### Types of Inheritance
- **Single Inheritance**: a child class inherits from exactly one parent class.
- **Multiple Inheritance**: child class can inherit from more than one parent class.

## Polymorphism
Polymorphism allows objects of different classes to be treated 
as objects of a common superclass.
